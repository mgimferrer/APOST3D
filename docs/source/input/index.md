# Input reference

## General structure

The code requires the wavefunction information in a Gaussian-type formatted
checkpoint file `name-input.fchk` and an additional input file
`name-input.inp` requesting the type of calculation. The formatted
checkpoint file can be obtained directly from a Gaussian or Q-Chem run, or
generated by I/O converters such as [IOData](https://github.com/theochem/iodata).
In the `utils` folder, a Python file (`apost3d.py`) gathers interface
functions for [PySCF](https://github.com/pyscf/pyscf), including
[pyscf2fchk](https://github.com/psalse/pyscf2fchk) to generate an `.fchk`
file from a PySCF run.

## Input file structure

The input file is a free-format ASCII file containing one or more input
blocks enclosed between a header (`# HEADER`) and a `#` sign, that gather
the desired options for the calculation. The main and mandatory input block
is `# METHOD`, in which both the Atom in Molecule (AIM) scheme and the type
of analysis (one or more) to be performed must be indicated. Additional
options like creating cube files or defining fragments are also specified
in this block. Some WF tools or options require additional block sections
for tool-specific options. The order of keywords within a block section is
indifferent, but keywords are case-sensitive.

See the pages in this section for the full keyword reference by block, plus
worked [input examples](examples.md).
